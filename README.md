# Income Prediction

Predicting whether a person earns more than $50K from 1994 US Census data. Paper: [`income-prediction.pdf`](income-prediction.pdf)

## Abstract

Occupation, education, relationships, and demographics say a lot about something harder to observe: income, which shapes opportunity, access to resources, and quality of life. I tune two classifiers, Locally Weighted Learning (LWL) and JRip (Weka's implementation of the RIPPER rule learner). Error analysis and tuning lift LWL from 80.8% to 86.4%, and tuned JRip reaches 88.8%, above the 86% reported by prior work on the same dataset.
